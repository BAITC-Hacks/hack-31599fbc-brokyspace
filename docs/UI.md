# MoneyGraph UI system

Интерфейс выглядит как современный банковский продукт, а не техническая AI-панель. Основной принцип — спокойная визуальная иерархия: сначала движение денег и понятные цифры, затем клиенты, маршруты, группы и сигналы проверки.

## Визуальная система

| Токен | Значение | Назначение |
|---|---|---|
| Background | `#F4F7F5` | нейтральный фон страницы |
| Surface | `#FFFFFF` | карточки, таблицы и навигация |
| Primary | `#16B86A` | действия, активное состояние и денежный поток |
| Secondary | `#5D86EA` | дополнительный финансовый акцент |
| Text | `#17211B` | основной текст |
| Muted | `#6E7C74` | подписи и вторичные данные |
| Border | `#DFE8E2` | лёгкое разделение поверхностей |

## Компоненты

- Hero объясняет продукт одной фразой и содержит нативную CSS 3D-сцену банка, монет и переводов.
- Transfer strip показывает количество переводов, оборот, средний перевод и активные связи.
- Финансовый обзор сравнивает крупнейшие маршруты, частоту и объём операций.
- KPI-карточки используют белую поверхность, тонкую границу и не отвлекают тенями.
- Навигационные вкладки имеют мягкое зелёное активное состояние без неоновых эффектов.
- Карточка клиента отделяет факты, полноту наблюдения и следующий запрос.
- Network canvas остаётся светлым; фиксированные цвета ролей нужны только для чтения структуры.
- Documents workspace хранит внешние материалы отдельно от рассчитанных метрик.

## Анимация и доступность

3D-сцена построена на `perspective`, `transform-style: preserve-3d` и CSS keyframes. Она не загружает внешние библиотеки или изображения, не перекрывает данные и автоматически останавливается при `prefers-reduced-motion: reduce`. На экранах уже 980 px hero переходит в одну колонку.

## Принципы

1. Финансовая статистика важнее декоративных элементов.
2. Зелёный кодирует действие и денежный поток, цвета ролей — только сетевую функцию.
3. Документные сведения визуально и логически отделены от рассчитанных фактов.
4. Интерфейс сохраняет читаемость на ноутбуке, планшете и телефоне.
5. Все визуальные элементы воспроизводятся локально без CDN.
